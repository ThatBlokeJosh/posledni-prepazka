# Poslední přepážka

Návrh týmové textové adventury pro 4IT107 Programování v Javě. Technik na napadené vesmírné stanici obnovuje systémy a hledá cestu k únikovému modulu.

- [Návrh k odevzdání v PDF](output/pdf/posledni-prepazka-navrh.pdf)
- [Upravitelný zdroj návrhu](navrh.md)

Před odevzdáním doplňte jména a xname čtyř členů týmu v šesté části návrhu a potvrďte rozdělení práce. Údaje lze doplnit v místní kopii.

PDF se regeneruje příkazem `python render_pdf.py`. Skript používá Python s balíčkem ReportLab a fonty Noto Sans Regular a Bold. Cestu k fontům lze zadat proměnnou `NOTO_FONT_DIR`.
